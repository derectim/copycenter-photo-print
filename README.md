# Конструктор фотопечати Копицентр.РФ

[Предпросмотр страницы услуги](./service.html) показывает вход в загрузчик под существующим описанием фотопечати. Нажмите «Открыть загрузчик». При первом посещении появится окно демовхода, после входа текущий браузер сразу открывает конструктор. Выбор и перетаскивание файлов доступны в самом конструкторе.

Чтобы попробовать личную библиотеку, черновики, фильтры и редактор области печати, нажмите **«Войти в демо»**. У демо один локальный профиль этого браузера. Для проверки QR откройте показанную ссылку во второй вкладке того же браузера. На установленном сайте CMS телефон и компьютер входят в один аккаунт, а фотографии хранятся на сервере магазина. Общая квота — 20 ГБ. Черновик хранится 3 дня, альбомные фото и оплаченные заказы — один календарный месяц.

В демо заказ сохраняется только в браузере, где он создан. Нажмите **«Создать демозаказ»** после проверки состава. В [разделе «Заказы»](https://derectim.github.io/copycenter-photo-print/admin.html#orders) можно скачать печатный ZIP и отдельно посмотреть спецификацию заказа. В ZIP лежат папки готовых JPEG по параметрам печати. Фотографии iPhone в HEIC и HEIF конвертируются на устройстве. При необходимости конструктор загружает отдельный локальный декодер [heic-to](https://github.com/hoppergee/heic-to).

[Открыть демо](https://derectim.github.io/copycenter-photo-print/) · [Настроить демонстрационные тарифы](https://derectim.github.io/copycenter-photo-print/admin.html) · [Скачать пример ZIP с четырьмя отпечатками в двух папках](examples/KIT_DEMO-PRINT.zip?v=2.2.3)

Нажмите «Добавить пример» или загрузите свои фотографии. Выберите форматы, параметры и тираж, затем нажмите «В корзину». Из корзины перейдите к оформлению и выберите пункт выдачи. После создания демозаказа можно скачать ZIP для оператора. В имени архива указаны код выбранного филиала и номер заказа. Демо работает в браузере. Изменения демонстрационных тарифов сохраняются только в браузере посетителя.

Для квадратного отпечатка выберите **10 × 10 см**. Откройте редактор снимка, чтобы приблизить фотографию, сдвинуть кадр и примерить белую, кремовую или чёрную рамку «Полароид». Кнопка **«Редактировать все фото»** под галереей применяет выбранные настройки к снимкам текущего формата. В ZIP каждый экземпляр представлен отдельным JPEG с выбранным кадрированием и рамкой.

В редакторе область печати можно перемещать и менять за углы прямо на исходном изображении. Вкладки «Кадр», «Цвет» и «Рамка» дают поворот, отражение, фильтры, ручную коррекцию, цвет и поля рамки в миллиметрах. Оценка разрешения показывает возможную потерю чёткости после обрезки. В боковой панели стоимость расписана по каждому формату. При двух копиях в рабочей папке архива появятся два JPEG.

Для локального запуска выполните `python -m http.server 4179 --bind 127.0.0.1` в папке репозитория и откройте [локальную страницу](http://127.0.0.1:4179/).

Действующий магазин подключается отдельным модулем Битрикса. На GitHub Pages размещена клиентская демонстрация. Исходные базовые цены и логотип взяты со [страницы услуги Копицентр.РФ](https://копицентр.рф/service/photo_printing/). Тариф 10 × 10 и дополнительные услуги иллюстрируют возможности настройки. Примерные фотографии созданы специально для демонстрации. Шрифт Manrope распространяется по лицензии SIL Open Font License из папки assets.
